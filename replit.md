# InfinityWork IT Solutions Website

## Overview
A professional static website for InfinityWork IT Solutions, showcasing IT services including web development, cloud services, SEO optimization, cybersecurity, IT consulting, and technical support.

## Project Architecture
- **Type**: Static HTML/CSS/JavaScript website
- **No build system required** - serves files directly
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **External Dependencies**: Font Awesome icons (CDN), Google Fonts (CDN)

## File Structure
- `index.html` - Main website page
- `styles.css` - All styling for the website
- `script.js` - Form validation and interactive features
- `attached_assets/` - Company logo images
- `google-apps-script.js` - Google Apps Script for form backend (deployed separately)
- `GOOGLE_SHEETS_SETUP.md` - Instructions for setting up form submission
- `TROUBLESHOOTING.md` - Common issues and solutions

## Development
The website runs on a simple Python HTTP server on port 5000.

## Deployment
Configured as a static site deployment serving the root directory.
